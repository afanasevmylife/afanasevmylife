# Hi, I'm afanasevmylife

I build and run **AI agents** - and I manage the process around them like an engineering discipline, not a prompt lottery.

## What I do

- **Autonomous agent pipelines** on the [Pollinations](https://github.com/pollinations/pollinations) platform: memory agents, code agents, PR-review bots, demo NPCs.
- **Agent process engineering** - ProF4A: plan-first specs, independent review, adversarial cross-inspection, proof-of-work tests. An agent that writes its own instructions gets graded by someone else.
- **Open-source contributions**: merged PRs and quest work in pollinations/pollinations (news deploy pipeline review, agent docs, demo agents).
